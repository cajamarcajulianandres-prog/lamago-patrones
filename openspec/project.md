# Proyecto: Lamago – Patrones de diseño

Sistema pequeño que modela la reserva de paquetes de decoración para quinceañeras
de Lamago (negocio familiar de alquiler de decoración en Bogotá).

- Lenguaje: Python 3.10+
- Código en `src/`, pruebas en `tests/`
- Metodología: SDD (Spec-Driven Development) con OpenSpec: primero la especificación, luego el código.
- Patrones: 1 creacional (Builder) + 3 estructurales (Composite, Decorator, Cache Proxy) + Facade como punto de entrada.
